# OSG-DOST

Case Monitoring & Management System for the OSG DOST Task Force — Department of Science and Technology.

## Stack

- React + Vite
- Tailwind CSS
- Supabase (optional) or local browser storage

## Local development

```bash
npm install
npm run dev
```
